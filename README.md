## What I'm building

**[slopfence](https://github.com/syedmuhdahmad/slopfence)** is a fast, deterministic quality gate for AI-assisted code. It catches hallucinated packages, tests that can't fail, placeholder stubs and leftover chat text before they get merged. It runs as a CLI, a GitHub Action or a pre-commit hook.

```
pip install slopfence
slopfence --diff main
```

**[Alchemist-QA](https://github.com/syedmuhdahmad/Alchemist-QA)** is a set of Claude Code plugins that work like a QA team. Give it a work item and it analyses risk, designs tests, automates them, reports defects and checks exit criteria, following the ISTQB syllabi. It never edits your product code.

**[cursor-qa-agents](https://github.com/syedmuhdahmad/cursor-qa-agents)** is a Cursor agent setup for writing tests: a QA role, Vitest and Playwright skills, and a hook that stops the agent from editing application source.
